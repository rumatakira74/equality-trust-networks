# Прогон с эмулятором

## Перед запуском

1. Проверить остатки прошлого прогона: pgrep qemu, pgrep java, pgrep tnp-node, pgrep tnp-testnet — если висят, остановить (gradle --stop для java/Gradle-демонов).
2. Часы хоста не сдвигать без разрешения владельца.

## Запуск и работа

3. Эмулятор: emulator -avd <имя-из-мандата> -no-window (x86_64); дождаться загрузки: adb wait-for-device и adb shell getprop sys.boot_completed = 1.
4. Сборка по мандату (flutter build apk ...), установка: adb install -r <apk>.
5. Скриншоты: adb exec-out screencap -p > reports/<stage>/NN-имя.png — нумерация сквозная по шагам сценария, имя на английском (kebab-case).
6. Каждый шаг мандата фиксировать скриншотом или логом; при падении — чекпоинт-коммит (WIP + артефакты) с session-ID и отчёт о состоянии.

## Уборка (обязательна после каждого прогона)

7. adb emu kill (или adb -s <emulator> emu kill).
8. gradle --stop (Gradle-демоны).
9. pgrep qemu java tnp-node tnp-testnet — пусто; при остатках завершить их.
10. Незакоммиченные бинарники сборок из корня репо удалить (не коммитить).
11. Сверить рабочее дерево (git status) и сделать чекпоинт-коммит артефактов прогона.
