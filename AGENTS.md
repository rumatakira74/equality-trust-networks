# AGENTS.md — правила CLI-агента в этом репозитории

Проект: Equality Project (платформа сетей доверия). Спека — docs/KNOWLEDGE-*.md (RU — оригинал, ENG — перевод). План — docs/development-plan.md. Вопросы — QUESTIONS.md. Мандат этапа — prompts/stage-*.md.

## Ветки и публикация

- Каждый этап/мини-этап — отдельная ветка от свежего origin/main. Перед стартом: git fetch, сверить tip main с ожидаемым в мандате.
- Пуш ветки и merge в main — ТОЛЬКО после явного подтверждения владельца. Команды git push и git merge не в allowlist: их запуск всегда согласуется отдельно.
- Remote-ветки не удалять. Историю не переписывать: без rebase, filter-branch, force-push.

## Мандат и спека

- Выполнять мандат из prompts/stage-*.md буквально, пункты по порядку, своего не вносить. Промпт не редактировать.
- Спеку docs/KNOWLEDGE-*.md править только если мандат прямо требует. README.md не трогать. Документационные репозитории (equality-user-docs, equality-programming-docs) не трогать.
- Открытые вопросы — PENDING: зафиксировать в отчёте и продолжать, не додумывать.

## Чекпоинты

- Промежуточный коммит: после каждого завершённого шага мандата и ориентир раз в ~30 минут активной работы (по меткам времени в выводах инструментов). В сообщении коммита — session-ID.
- После рестарта сессии (краш, --continue, новая сессия): до любых действий сверить живое состояние с последним коммитом ветки и отчитаться планом. Ничего не перезапускать и не повторять без сверки.

## Коммиты и дерево

- Все правки одного файла — в одном коммите; несколько файлов — одним коммитом, если меняются согласованно.
- Финальный коммит этапа — чистое дерево (git status чист). Бинарники и scratch не коммитить; крупные временные файлы — вне репо (/tmp). Скриншоты, логи и метрики прогонов — коммитить в reports/.
- Не коммитить незакоммиченные бинарники сборок из корня репо (tnp-node, tnp-testnet и т.п.).

## Прогоны и уборка

- Часы хоста не сдвигать без явного разрешения владельца.
- После каждого прогона: остановить Gradle-демоны, завершить tnp-node/tnp-testnet/qemu, проверить pgrep — процессов не осталось. Перед следующим прогоном — снова pgrep.
- Перед финальным коммитом этапа: go test ./... (и -race по мандату), flutter analyze, flutter test — зелёные.
