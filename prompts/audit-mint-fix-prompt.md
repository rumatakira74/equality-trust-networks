# Промпт blind-аудита темы mint-fix

Ветка: `audit-mint-fix` от tip ветки `mint-fix`. Слепая схема: пункты 1–5 выполнить ДО открытия отчёта исполнителя (`reports/REPORT-MINT-FIX.md` на ветке mint-fix); пункт 6 — сверка с отчётом; пункт 7 — спец-проверки. Репо eq — только чтение (отчёт A9 `reports/REPORT-A9-SIMULATION.md` в eq main — источник описания дефекта). Код tnp — только чтение + каталог reports/.

1. Фикс по коду (не по отчёту): найти проверку M7 в `core/ledger/validate.go` — какой период передаётся в `CheckMintChallengeWindow`; подтвердить, что якорь — текущий период выпуска (`l.tt.period`), а не заявленный `mp.Period`; механизм txNow (TimestampClaim) не сломан.
2. Математика фикса: слот = period_start + H(addr‖period) mod period_secs внутри текущего периода; доказать перебором/свойством, что окно ±48 ч всегда пересекается с текущим периодом на ≥ 48 ч (достижимость каждый период для любого адреса); поглощающее состояние устранено (компенсация M6 в пределах accrual_window), осознанный пропуск 6+ периодов по-прежнему даёт E_ACCRUAL_WINDOW.
3. protocolVersion-bump: версия в genesis поднята на 1; все фикстуры/векторы/шаблоны обновлены; tx с прежней версией → E_VER (C2); живых сетей нет (миграция не нужна) — подтверждение в коде и отчёте исполнителя.
4. Единообразие M7: все пути применения (headless, net gossip/sync, replay, mobile-мост) проверяют окно одинаково от txNow; `SkipMintChallengeWindow` — только песочница; обход через sync-подачу закрыт.
5. Тесты и гигиена: прогнать полный локальный набор (gofmt/vet/`go test ./...`/-race по затронутым пакетам; GOMAXPROCS=6, контроль памяти, стоп при <2 ГБ); все новые тесты мандата (a)–(h) существуют и проходят; дифф ветки — только предмет темы; секретов и файлов >1 МБ нет.
6. Сверка с отчётом исполнителя: каждое заявление — подтвердить/опровергнуть по коду; расхождения — находки AUDIT-MINT-FIX-NN с file:line.
7. Спец-проверки: M3/M4/M5/M6 не изменены; двойной выпуск (evidence DoubleMint) совместим с новой семантикой окна; genesis-поле 61 не тронуто; формула слота hashThree(addr, period) не менялась (чекпоинт-хеш — PENDING, не должен быть реализован); спека 7.6 RU/ENG — хирургическая (только якорь окна + примечание о PENDING), версия +1, запись в истории версий; README/DISCLAIMER темой не трогались.

Отчёт: `reports/REPORT-AUDIT-MINT-FIX.md` + артефакты в `reports/audit-mint-fix/`. Вердикт: «готова к merge» / «готова с замечаниями» / «переработать» + блокеры/находки с приоритетами. Числа замеров и прогоны — воспроизводимы (команды в отчёте).
