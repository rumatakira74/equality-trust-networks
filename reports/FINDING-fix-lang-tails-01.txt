Что локализовано в этой теме
----------------------------
Через ARB и существующий канал (platform.tnp/app) переведены:
- негативная кнопка биометрического промпта: Dart передаёт l.btnCancel
  аргументом cancel вызова signTx, мост использует его в
  authenticatePlain и signWithBiometric (fallback — «Cancel», шаблон ARB);
- тексты ошибки NONODE: код моста переводится на стороне интерфейса
  (extension LocalizedError.errorText, ключ errNoNode) во всех точках
  показа ошибок (17 мест в 8 экранах).

Что передать из Dart нельзя (архитектурно — не в этой теме)
-----------------------------------------------------------
1. Уведомление foreground-сервиса узла (NodeService.kt):
   - канал «Узел сети» (CHANNEL_ID tnp_node);
   - заголовок «Сети доверия»;
   - текст «Узел сети доверия работает».
   Строки создаются в onStartCommand сервиса, вне вызова Dart: сервис
   поднимается по Intent, а текст уведомления формируется асинхронно и
   не связан с конкретным MethodChannel-вызовом. Передача строк из Dart
   потребовала бы менять контракт сервиса (Intent extras) — это
   архитектурная правка, мандатом запрещена.

2. Label приложения «Сети доверия» (manifestPlaceholders appLabel,
   app/android/app/build.gradle.kts; по умолчанию в сборке конструктора).
   Значение задаётся при сборке APK конкретной сети и попадает в манифест;
   из Dart не передаётся. В системном биометрическом промпте этот label
   виден рядом с локализованным заголовком.

Предложение (на решение владельца)
----------------------------------
Оба случая закрываются штатными средствами Android — ресурсами
values-<lang>/strings.xml, сгенерированными из ARB на этапе сборки
(единый источник переводов сохраняется):
- notification_channel_name / notification_title / notification_text —
  в NodeService брать из R.string вместо литералов;
- app_name — в манифесте android:label="@string/app_name", значения по
  локалям из тех же ARB.
Альтернатива для уведомления без генерации ресурсов: передавать три
строки в Intent extras при nodeStart (контракт сервиса расширяется,
нужен отдельный мандат).

Остаток по тому же классу (вне списка FINDING-03, не правился)
--------------------------------------------------------------
- NOTFOUND «транзакция не найдена» (FlutterBridge.kt, 3 места) и
  fallback-заголовок «Подтвердите операцию» — в пути вызова Dart, могут
  быть закрыты тем же приёмом, что NONODE (код -> ARB), отдельным пунктом.
