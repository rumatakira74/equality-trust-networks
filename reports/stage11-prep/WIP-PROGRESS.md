## Находки прогона (кандидаты в PENDING/отчёт)

1. E_SIG ~50% на app-подписях: этап 9 (09738c0) low-s в ядре; Keystore-подписи не нормализованы
   (Kotlin BiometricGate/KeystoreWallet.sign). Регистрации проходили с 4–7-й попытки.
2. Окно челленджа в приложении: MintWindowJSON проверяет слот ТЕКУЩЕГО периода, ядро — заявляемого
   (№39 буквальная семантика) → кнопка Mint отключена при фактически открытом окне (скрин
   05-appA-mint-window-ui-bug.png); выпуск A из приложения невозможен, баланс создан переводом.
   В 8.1-2 наблюдалось как «окно закрыто», не диагностировано.
3. IME/ввод на эмуляторах: lock-экран и отдельные поля периодически «мертвы» (ImeTracker
   onFailed PHASE_CLIENT_VIEW_SERVED / STATUS_TIMEOUT; input text/keyevents/тапы по паду не
   попадают). Рестарт Gboard помогает не всегда. Из-за этого: duress-PIN у A не удалось задать
   (переключатель тумблером выключился, поле не принимало ввод) — шаг 3 мандата (приманка) заблокирован;
   PIN-вход на lock-экране нестабилен.
4. Генерация ключа с аттестацией на сдвинутых часах падает (E2, API 36: «Failed to generate key
   pair», мгновенно; на реальном времени — ок). Регистрации приложений вести в реальном времени.
5. UX-разрыв миграции: StartMigrationScreen генерирует случайный nonce и НЕ показывает его —
   гардиан не может подписать правильный MigrateStatement (нужен nonce+эпоха). App-флоу миграции
   неполноценен; планируемая демонстрация: app-попытка → E_MIGRATE_GUARDIANS (скрин) + протокольная
   часть миграции CLI-кошельками W9→W10 (тот же путь ядра).
