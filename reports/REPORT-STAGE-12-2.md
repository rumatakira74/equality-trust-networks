# Отчёт мини-этапа 12.2 — fingerprint-манифест: посевной круг и поставщики как публичные ключи

Дата: 01.11.2026. Ветка `stage12-2-fingerprints` от `eacd433`
(main содержит merge 12.1 `b73b224`). session-id:
`6bc76674-51ad-7c49-ac7a-437faaa50437`. Мандат:
`prompts/stage-12-2-prompt.md` (решение владельца 01.11.2026: PENDING №5
этапа 12, расхождения №2–№3 отчёта REPORT-STAGE-12.md).

## Итог

Манифест и genesis хранят fingerprint'ы: посевной круг — публичные ключи
(fingerprint = SHA-256(pub ‖ protocol_id), 7.2), поставщики —
fingerprint'ы; адреса нигде не хранятся — каждое устройство выводит их
из финального network_id: `SHA-256(fingerprint ‖ network_id)`. Цикл
само-сертификации (адреса не выводимы из network_id, зависящего от
манифеста с адресами) устранён целиком — и для посевного круга, и для
поставщиков. Обходные пути (senderAddr, предварительная деривация
network_id в конфигураторе) удалены. Wire-изменение — последнее до
живых прогонов: живых сетей нет, миграция не нужна, тестовые сети
пересозданы. Эмуляторный прогон rec/std/global + приложение на новом
wire — 33 артефакта (reports/stage12-2/).

## 1. Wire-изменения (старое/новое)

| Поле | Старое (v9.10) | Новое (v9.11, 12.2) |
| --- | --- | --- |
| `Manifest.SeedCircle[].SeedMember` | `{Address, PublicKey}` — адрес посевного фиксировался в манифесте ДО деривации network_id (обход цикла) | `{PublicKey}` — поле `Address` удалено из структуры и из кодирования (wire-поле 1); старые genesis-бинарники не декодируются (живых сетей нет) |
| `Profile.Providers` | адреса поставщиков (32 байта) | fingerprint'ы поставщиков (32 байта; wire-формат байтов не менялся — сменилась семантика) |
| Адрес посевного | из манифеста (зафиксирован при сборке) | выводится: `crypto.AddressOfKey(pub, network_id)` = SHA-256(SHA-256(pub ‖ protocol_id) ‖ network_id) от финального network_id |
| Членство поставщика | сравнение адреса со списком адресов | fingerprint из параметров → выведенный адрес; кошелёк поставщика не обязан существовать в момент проверки (`Ledger.inProviders`) |
| Членство посевного | по адресу в манифесте | по fingerprint (публичный ключ манифеста); принадлежность заявителю — подпись (C8 по ключу манифеста) |
| Сборка сети | адреса посева/поставщика согласуются с пред-network_id | дубликаты fingerprint'ов посевного круга и поставщиков, пустые публичные ключи — отвергаются (`profiles.ValidateGenesis`) |

Реализация: `core/wire/genesis.go` (SeedMember), `core/wire/genesis_decode.go`
(поле 1 удалено), `core/crypto/address.go` (`AddressOfKey` — единая точка
деривации), `core/ledger/state.go` (`SeedMembers(members, networkID, …)` —
сигнатура расширена), `core/ledger/modules.go` (`inProviders` по
fingerprint), `core/ledger/validate.go` (restricted-перевод через
`inProviders`), `cons/modes.go` (состав круга чекпоинтов выводится),
`core/profiles/profiles.go` (дубликаты/пустые ключи).

## 2. Удалённые обходные пути

- **`senderAddr`** (cmd/tnp-testnet/main.go): адрес отправителя брался из
  манифеста для посевных (адреса фиксировались до финального network_id).
  Удалён; все команды используют `addrOf(key, network_id)` — единая
  деривация. Расхождение №2 отчёта этапа 12 закрыто.
- **Предварительная деривация network_id** в configure (адреса посева
  вычислялись до добавления круга в манифест). Удалена: круг — только
  публичные ключи, network_id деривируется один раз (`FinalizeGenesis`).
  Расхождение №3 и PENDING №5 закрыты.
- **`-provider-seed`**: было «поставщик = адрес посевного кошелька из
  манифеста», стало «поставщик = fingerprint посевного кошелька» —
  удобство сохранено (решение 2 мандата); поставщик не обязан быть
  посевным участником: `-providers` принимает любые fingerprint'ы.

## 6. Для спеки v9.11 (спека не правилась — отдельный заход)

1. **Раздел 3.3 (манифест)**: SeedMembers — публичные ключи участников
   (fingerprint = SHA-256(attestedPublicKey ‖ protocolId), 7.2); адреса
   в манифесте не хранятся. Убрать упоминания адресов посевного круга
   как полей манифеста.
2. **Раздел 6.2 (поставщики)**: providers в параметрах сети —
   fingerprint'ы; членство проверяется по fingerprint (адрес выводится
   из network_id), поставщик не обязан быть посевным участником.
3. **Раздел 7.2 / деривация адреса (вопрос №2)**: закрепить
   `address = SHA-256(fingerprint ‖ network_id)` от ФИНАЛЬНОГО
   network_id; указать, что само-сертификация network_id
   (H(manifest ‖ genesis)) больше не циклична: манифест адресов не
   содержит.
4. **Раздел 2 / wire-формат genesis**: SeedMember — одно поле
   (public_key, wire-поле 2); поле 1 (address) удалено; genesis-бинарники

5. **Сборка сети (раздел 4/конфигуратор)**: дубликаты fingerprint'ов
   посевного круга и поставщиков, пустые публичные ключи — отвергаются

## 7. PENDING (за владельцем, не додумано)

1. **applicationId 12.1 — hex-цифра в начале hash8** (найдено при сборке
   APK в этом прогоне): AAPT отверг `io.equality.cirrus.783da646` —
   сегмент Android-пакета не может начинаться с цифры; hash8 начинается
   с hex-цифры в 10/16 случаев (62,5%). Формула 12.1
   `io.equality.<sanitized-slug>.<hash8>` в большинстве случаев даёт
   невалидный пакет. В прогоне обойдено подбором сети с hash8 с буквы
   (`e5796f9c`); нужно решение владельца (варианты: префикс-сегмент из
   букв, санитизация hash8, другой разделитель сегментов).
2. **E_BURNED на живых часах** — календарная граница (месяц): прогон 12.2
   снял шаги до границы; сгорание подтверждено юнит-тестами и прогоном
   этапа 12. Для полного прогона на живых часах нужен месяц календарного
   времени или отдельное решение о тестовом профиле с короткими
   периодами.
3. **Мораторий переводов (14 сут)** блокирует исходящий перевод
   свежезарегистрированного кошелька — перевод из приложения в прогоне
   не показан (та же календарная природа); входящие переводы работают.
4. **Среда сборки AAR**: `gomobile bind` на Go 1.27 требует
   `-ldflags "-checklinkname=0"` (anet v0.0.5 линкуется к
   `net.zoneCache` через linkname) — отметить в чек-листе сборки.
5. **Эмуляторные находки**: AVD, использовавшийся в этапе 12, остаётся с
   PIN-экраном блокировки (биометрика требовала безопасный замок) —
   перед новым прогоном `-wipe-data`; debug-сборка обязательна для
   синтетической цепочки аттестации на эмуляторе (8.1); full-уровень
   узла требует charging + Wi-Fi (в AVD включён `hw.wifi=yes`).
